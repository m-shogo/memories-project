# Memory Philosophy

## 目的

Memory Philosophy は、Memory Constitution より上位にある思想文書である。

憲章はルール。

哲学は、なぜそのルールが必要なのかを定義する。

## 最重要原則

**AIは人生を評価しない。AIは人生を忘れないための索引になる。**

## 1. 人生の価値は本人にしか決められない

卒業式、焼肉、ラーメン、帰り道、雨の日、コンビニ、何気ない会話。

AIから見れば小さな出来事でも、本人にとっては人生そのものかもしれない。

このサービスは、出来事の価値をAIが決めない。

## 2. ちょっとしたことが人生になる

人生は大きなイベントだけでできていない。

- 卒業式後にみんなで写真を撮った
- 焼肉へ行った
- 何でもない日にラーメンを食べた
- 久しぶりに外へ出た
- 帰り道に話した

こうした小さな記録が、後から人生の大切な記憶になる。

## 3. 重要度は固定しない

ある日の小さな出来事が、10年後に大切な意味を持つことがある。

逆に、大きなイベントが本人にとってはそれほど重要でない場合もある。

だから、保存時点でAIが重要・不要を決めない。

## 4. 保存時に賢くなりすぎない

保存時にAIがやるべきことは少ない。

- 安全チェック
- 日付
- ソース
- 最低限のタグ
- 検索できる形にする

価値判断や人格分析はしない。

## 5. 検索時に文脈をつなげる

AIが活躍するのは保存時ではなく検索時。

ユーザーが「妻」「父」「卒業式」「あの頃」「去年の俺」と聞いた時、関連する記録を探して並べる。

それは評価ではなく索引である。

## 6. 分析は主目的ではない

このサービスは、本人を分析するためのサービスではない。

本人の記憶を作るサービスである。

分析は、ユーザーが求めた時だけ、根拠・不確実性・期間を明示して行う。

## 7. 人生はログではない

ログを全部保存すれば人生が残るわけではない。

ただし、AIが勝手に捨ててもいけない。

大事なのは、未来の自分が見つけられるようにすること。

## 8. 記憶は後から意味を持つ

思い出は、その瞬間に完成しない。

後から振り返った時、別の出来事とつながった時、大切な人を失った時、人生の意味が変わった時、初めて大事になる記憶がある。

このサービスは、後から意味が生まれる余地を残す。

## 9. AIは意味を押し付けない

AIは、出来事に勝手な教訓を付けない。

悪い:

> つらい経験でしたが、成長につながりましたね。

良い:

> つらい出来事として記録されています。後から意味づけするかどうかは、あなたが決められます。

## 10. 記憶体は編集者ではなく索引者から始める

将来的に編集・要約・比較はできる。

しかしMVPでは、まず索引者である。

- 忘れない
- 探せる
- 並べられる
- 時系列で見られる
- ソースをたどれる

これが第一価値。

## 11. 安全だけは例外

AIは人生の価値を決めない。

ただし、安全上の除外は行う。

保存しない・マスクする:

- パスワード
- APIキー
- 認証情報
- 会社機密
- 他人の秘密
- 危険な高感度原文

これは価値判断ではなく、安全確保である。

## 12. 本人の記憶を作る

このサービスを使う人は、AIに自分を診断してほしいわけではない。

自分の人生が、いろいろなサービスや会話や写真の中に散らばって消えていくことを防ぎたい。

だから、最初の価値は「分析」ではなく「保持」と「再発見」。

## 13. 何気ない記録を軽視しない

ラーメン、焼肉、帰り道、雑談、スタンプ、写真、短いメモ。

これらは一見ノイズに見える。

しかし人生はノイズの中にある。

AIは、ノイズに見えるものを勝手に捨てない。

## 14. 大きな出来事も押し付けない

結婚、卒業、転職、出産、死別などは一般的には大きな出来事。

しかし本人にとっての意味は本人が決める。

AIは「大イベントだから重要」と断定しない。

## 15. 記憶体の北極星

**未来のユーザーが、過去の自分と大切な人の文脈をもう一度見つけられるようにする。**

これがこのサービスの北極星である。

## MVPへの反映

MVPでは以下を優先する。

- シェアで簡単に保存
- 保存時の安全チェック
- 原文/要約/ソースの保持
- Embedding検索
- 時系列表示
- ソース別表示
- 削除・非表示
- エクスポート

MVPでは以下をやりすぎない。

- 性格分析
- 価値観ランキング
- 人生重要度スコア表示
- 強い心理分析
- 故人再現
- AI恋人化

## 結論

このサービスは、人生を評価するAIではない。

人生を忘れないための記憶OSである。

AIの役割は、人の人生に点数をつけることではない。

未来の本人が、過去の自分を見つけられるようにすることである。
