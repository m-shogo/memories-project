## Material failure risk A — well-formed but incomplete commit enumeration

- **symptom:** The history checker validated the shape of `rev-list --reverse` output but could accept a well-formed list omitting, duplicating or substituting commit identities. This is a source-verified latent proof gap, **not** an observed mutation to production or learning history.
- **evidence:** Starting `so` HEAD `5071e90275089d25ce48ab98a13154c5d003a802` had strict 40-hex OID grammar but no independent `rev-list --count` check or terminal-list-to-captured-HEAD equality. Disposable fixture mocks returned empty, duplicated and baseline-substituted streams with valid byte grammar.
- **rootCauseOrUnknown:** Verified that syntax validation alone does not establish completeness of an external command's result. The Git executable/object store itself remains a trust boundary; no claim of Byzantine Git-proof completeness is made.
- **failedApproach:** Treating a syntactically valid commit enumeration as complete and relying only on the terminal live HEAD re-read.
- **correction:** [`89c08dd0`](https://github.com/m-shogo/memories-project/commit/89c08dd0650bc1add6c47f22f286288d48aacdb7) independently compares a bounded, canonical `git rev-list --count` against enumeration length, rejects duplicate OIDs and requires the captured HEAD as terminal commit.
- **recurrenceGuard:** Eight deterministic negative controls cover missing, duplicate, substituted, false-count, malformed and nonbytes count streams; an unmodified real-Git positive remains mandatory. The existing CI-reachable entrypoint independently pins the live check via parsed AST and five source mutations.
- **retryCondition:** Revisit if Git OID grammar/hash algorithm, history enumeration semantics, source AST, or exact-source CI changes. Do not rerun an unchanged permission, MinIO or canonical-transfer blocker.

## Material failure risk B — empty scoped diff stream masking an edit

- **symptom:** The checker previously accepted an empty `git diff-tree --name-status -z` stream as proof that a parent edge had no protected changes. An incorrectly empty transport could hide a real scoped edit.
- **evidence:** At `89c08dd0`, `if not raw: continue` had no independent scoped tree-difference confirmation. A disposable real-Git modified-record fixture and mocked empty `diff-tree` stream reproduced the potential false-negative boundary. No actual repository-history rewrite was observed.
- **rootCauseOrUnknown:** Verified missing independent tree-difference consistency check. A malicious or corrupted Git implementation could still lie consistently across both commands; this is not an atomic ref CAS or full object-store attestation.
- **failedApproach:** Relying solely on one name-status output stream to decide whether a parent edge had changes.
- **correction:** [`19431882`](https://github.com/m-shogo/memories-project/commit/194318823eefdb8bcfca8ea6902c5cf67ca2fd3b) runs a separate `git diff --quiet --no-ext-diff --no-textconv` over the same immutable parent/commit and protected pathspecs. It rejects empty/nonempty disagreement, invalid exit status, nonbytes or noisy quiet output.
- **recurrenceGuard:** Five deterministic real-Git/mocked-output negatives cover empty name-status, false quiet, invalid exit status, unexpected stdout and stderr. An independent CI-reachable AST binder pins the exact quiet-diff command, returncode/type checks and comparison; four source mutations must be rejected.
- **retryCondition:** Revisit on a changed diff pathspec, Git output semantics, source-call shape, or observed CI regression. Do not weaken fail-closed handling to accommodate an unrelated CI failure.
