# Supplemental OPS learning — upload-route reconcile must exclude append-only history (2026-10-31)

This is append-only operational learning only. It is never production, backup/restore, RPO/RTO/skew, drill, credential, traffic, readiness, generation/objective, request-bound recovery, typed eight-domain non-resurrection, independent review or promotion evidence.

## Material failure: broad route-label rewrite could touch learning

- **symptom:** The Upload Route reconciler enumerated all matching files under `docs/` and globally replaced an obsolete route label. The scan excluded fixtures and evidence, but not canonical or supplemental append-only learning. A historical record containing the obsolete label could therefore be rewritten. This was a source-proven latent risk; no actual historical-record mutation was observed.
- **evidence:** The original `current_authority_files()` included all `.md` files under `docs/operations/`, including the 4.17 MB canonical learning file and hundreds of supplemental records. The loop in `main()` used `value.replace(OLD_LABEL, NEW_LABEL)` and `atomic_write_text` for every matching scanned file. A disposable scanner fixture confirmed an ordinary route guide should remain eligible while all four learning scopes must not be.
- **rootCauseOrUnknown:** Verified: recursive scanner scope was broader than mutable route authority, and `Path.is_file()` follows file symlinks.
- **failedApproach:** Relying on the old `docs/fixtures` and `docs/evidence` exclusions to protect all immutable operational history.
- **correction:** [88ea7bb2](https://github.com/m-shogo/memories-project/commit/88ea7bb2c78bbe3281746d156fdc871ec4203312) excludes canonical `AUTONOMOUS-OPS-LEARNING.md`, `autonomous-learning-records/`, `autonomous-learning-addenda/`, and `docs/operations/learning/`; it rejects candidate symlinks. A disposable negative fixture in the existing rollback validator covers these exclusions, ordinary mutable input inclusion and a symlink alias.
- **recurrenceGuard:** [20997d51](https://github.com/m-shogo/memories-project/commit/20997d515410b31071d3f921a9f4fb535ad07b06) adds an independent pre-MinIO invocation of the real rollback validator from the already CI-reachable entry-doc validator. [058ed999](https://github.com/m-shogo/memories-project/commit/058ed9999da2bdf9fb11a52102eaaada3d90de54) mirrors the new scanner exclusion in the source-negative inventory and adds four protected-scope fixtures. [9ff46b4a](https://github.com/m-shogo/memories-project/commit/9ff46b4a42dd7ce1ff6a5637980b6b95f44b7a58) independently asserts that canonical learning remains a CI trigger but not a mutable snapshot input.
- **retryCondition:** Revisit on a reviewed change to the reconciler scanner, protected learning directory layout, symlink policy, or source-negative inventory. Never retry unchanged external MinIO HTTP 401 or workflow-write permission blockers.
