## Material failure — event shadow and repeated escaping pitfall

- **symptom:** The generation publisher read-only source guard did not independently reject duplicate top-level `on`/`jobs`, shadowed `push`, or an unreviewed event. The initial new guard rejected even the canonical workflow because its string delimiters were double-escaped.
- **evidence:** Pre-change `classify_generation_publisher_coupling` checked a known `push` substring and `workflow_dispatch` marker but did not enforce unique YAML event/top-level keys. [`307b7dce`](https://github.com/m-shogo/memories-project/commit/307b7dcec280e700888970f7e72ce074437942f2) attempted to add four negative mutations. No production publisher bypass or authority drift was observed.
- **rootCauseOrUnknown:** Verified static coverage gap plus repeated double-escaped newline literals in the new Python source matcher and negative mutation strings. The canonical publisher had a single reviewed `on` and `jobs` key; malicious event shadowing in production is unknown.
- **failedApproach:** Trusting exact safe-looking trigger substrings despite possible later YAML overrides, then using unverified nested JavaScript-to-Python backslash escapes even though an earlier matcher failed for the same class.
- **correction:** [`9e108172`](https://github.com/m-shogo/memories-project/commit/9e108172518eafd5a359e252a4f94ec45835c954) replaces escaped newline matching with `splitlines()` and builds mutations from `chr(10)`, checking unique top-level `on`/`jobs` and exact `pull_request`/`push`/`workflow_dispatch` event keys. [`6666728e`](https://github.com/m-shogo/memories-project/commit/6666728e4f3c1a4ad40dab233346e4ecf5c499a1) explicitly rejects inert negative mutations before classifying their expected failures.
- **recurrenceGuard:** Existing publisher-free, read-only `scripts/validate-memory-os-backup-restore-generation-evidence-reconcile-workflow-negative.py` now runs 12 semantic publisher guards: bounded source lease, branch/event condition, duplicate/quoted job keys, duplicate top-level `on`/`jobs`, duplicate `push`, and unreviewed `schedule`. The new inert-mutation assertion prevents a literal-backslash fixture from silently passing as a real negative.
- **retryCondition:** Revisit only if publisher YAML event/job structure, source lease, static parser or CI reachability changes. Do not retry the double-escaped newline construction; use `splitlines()`/`chr(10)` or an independently checked fixture. Unchanged MinIO 401, workflow write-permission and missing human production evidence remain scoped blockers.
