## Material failure — unbounded, inherited-environment local child validation

- **symptom:** The older local backup normalizer and coherent-recovery reconciler could launch a caller-provided repository path as a Python child without an explicit approved target allowlist, environment isolation, output suppression or execution timeout.
- **evidence:** At `a2c2938e`, both `run_validator(path)` helpers used `subprocess.run([sys.executable, str(path)], cwd=ROOT, check=False)` and checked the return code after execution. Approved production call sites selected the expected backup/operability validators (and coherent validator for the coherent reconciler). No unreviewed child launch, secret disclosure, production evidence or promotion was observed.
- **rootCauseOrUnknown:** Verified child-execution trust boundary gap: path authority was caller-supplied, and the child inherited `PYTHONPATH`, Git and loader configuration and could run without a bound. Reachability of an unreviewed caller through approved CI is unknown.
- **failedApproach:** Treating canonical main() call sites and an eventual zero child exit code as sufficient authorization and privacy control for a generic executable helper.
- **correction:** [`6320bb00`](https://github.com/m-shogo/memories-project/commit/6320bb00344187eb372b2b533bfa98013d35c021) restricts each helper to exact reviewed repository validator paths, rejects symlink/noncanonical leaves before launching, strips inherited Python/Git/loader variables, disables user site and bytecode writes, suppresses stdout/stderr, imposes 120-second timeouts and rejects noninteger or failed return codes with fixed-class failures.
- **recurrenceGuard:** The existing CI-reached `scripts/validate-memory-os-backup-authority-atomic-negative.py` now exercises approved-target subprocess positive controls for both reconcilers and rejects an unreviewed repository JSON without any subprocess launch, a boolean `True` exit code and a child timeout. Subprocess spies assert exact argv, cwd, timeout, private output and sanitized environment. Existing atomic rollback and source-ancestry tests remain active.
- **retryCondition:** Revisit only if a new reviewed backup/coherent validator is explicitly authorized, subprocess transport requirements change or exact-source CI detects a regression. Do not retry unchanged Quay MinIO HTTP 401, workflow permission or human production-evidence blockers.
