## Material failure

- **symptom:** The drill-generation binding validator checked the canonical Python module pathname and then used `SourceFileLoader.exec_module`, which could re-open the pathname after the identity check. A post-check symlink replacement of a module leaf or parent could redirect executable bytes to an unreviewed file.
- **evidence:** At starting HEAD `c5de256a`, `load_module` called `require_exact_repo_file`, then `spec_from_file_location` and `spec.loader.exec_module(module)` without a pinned source descriptor. This was an identified source-level time-of-check/time-of-use boundary; no actual malicious repository substitution or production compromise was observed.
- **rootCauseOrUnknown:** Verified separation between the checked pathname and the loader's later path-based source acquisition. Real-world exploitation is unknown.
- **failedApproach:** Treating a successful pre-import `resolve`/symlink check as proof that the same bytes would be executed by a later pathname-opening loader.
- **correction:** [`187f9723`](https://github.com/m-shogo/memories-project/commit/187f9723d9bef2381af4e1783d11ed34004ffa7d) pins each relative directory beneath the repository root with `O_DIRECTORY|O_NOFOLLOW`, opens the module leaf with `O_NOFOLLOW`, requires a single-link regular file and a 1 MiB source bound, compares pre/post descriptor and leaf metadata, rechecks canonical pathname identity, and executes compiled bytes from the pinned snapshot instead of calling `loader.exec_module`.
- **recurrenceGuard:** The existing CI-reached drill-generation binding reconcile negative suite now runs a positive module-source control and two synthetic post-check symlink-swap negatives (module leaf and parent), each asserting the external marker never executes. The tests operate only in an isolated temporary directory.
- **retryCondition:** Revisit on reviewed import-loader semantics, module source tree, Python interpreter/platform assumptions, negative-suite reachability or exact-source CI regression. Do not retry unchanged Quay MinIO HTTP 401, workflow permissions, missing external evidence or human-promotion blockers.
