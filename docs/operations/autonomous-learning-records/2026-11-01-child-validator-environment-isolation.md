- **symptom:** Five canonical child/post-validator launch sites invoked `sys.executable` without an explicit child environment. A successful exit could reflect an imported unreviewed module rather than execution of the canonical child assertions.

This is a demonstrated interpreter import-path failure mode, **not** evidence of actual CI compromise or production manipulation.
- **rootCauseOrUnknown:** Verified source-level inherited `PYTHON*`, `LD_*`, `DYLD_*` and `GIT_*` transport across these child validation boundaries. Whether an adversary could control the actual runner environment is unknown.
