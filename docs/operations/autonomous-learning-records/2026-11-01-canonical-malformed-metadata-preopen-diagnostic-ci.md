## Material failure 1 — malformed metadata escapes canonical acquisition

- **symptom:** The direct canonical reader's initial ancestor `lstat()` metadata inspection could raise an uncaught `AttributeError` if a synthetic or malformed metadata provider returned `None` or an object without `st_mode`. The leaf could likewise reach descriptor acquisition without validating the preflight metadata shape. No production fault is asserted.
- **evidence:** At starting HEAD `dc88dbe1`, the initial acquisition handler caught `OSError`, `ValueError` and `TypeError` but not `AttributeError`; the preflight leaf was assigned before `os.open` and its mode was first used only after opening. The direct-reader negative suite did not exercise malformed returned metadata at both boundaries.
- **rootCauseOrUnknown:** Verified incomplete normalization of malformed `lstat` return values and missing pre-open leaf mode validation; no ordinary CPython `lstat` defect was observed.
- **failedApproach:** Treating exception classes from `lstat` as exhaustive and relying on later descriptor metadata validation to reject malformed preflight values.
- **correction:** [`78970137`](https://github.com/m-shogo/memories-project/commit/7897013782cd4e5873bfee1d5cfdf2f1821b4ee9) normalizes acquisition `AttributeError`; [`15991b5d`](https://github.com/m-shogo/memories-project/commit/15991b5db19219bbf45c05d56d0e63032497c4b7) adds fail-closed leaf mode rejection before `os.open`.
- **recurrenceGuard:** [`9be5e338`](https://github.com/m-shogo/memories-project/commit/9be5e3386095c4c2e62a3f4589eb3240b8b8c680) adds four direct negative combinations (ancestor/leaf × `None`/missing-`st_mode`), requiring exact unreadable-authority rejection **without opening the canonical leaf**, external FD canary preservation and valid-read recovery. The existing direct FIFO and symlink negatives remain mandatory.
- **retryCondition:** Revisit on canonical metadata acquisition/interface changes, a newly observed malformed return class, or an exact-source regression. Do not retry unchanged external MinIO 401, workflow permissions or human evidence blockers.
