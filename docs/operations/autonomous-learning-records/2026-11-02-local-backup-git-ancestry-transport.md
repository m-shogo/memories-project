## Material failure — inherited Git executable and environment could influence local ancestry

- **symptom:** The older backup normalizer and coherent-recovery reconciler accepted a valid-looking local evidence SHA from an inherited-PATH Git executable; the coherent path also had no bounded timeout or transport exception handling.
- **evidence:** At `90b3ed8f`, `scripts/reconcile-memory-os-backup-authority.py::source_is_ancestor` invoked `["git", "merge-base", ...]` without an explicit child environment or timeout. `scripts/reconcile-memory-os-backup-coherent-authority.py` used the same inherited Git lookup without an exception boundary. The existing local foundation validator already pinned `/usr/bin/git` and stripped Git/loader environment variables. No actual forged local recovery evidence or production promotion was observed.
- **rootCauseOrUnknown:** Verified execution transport trust gap: the reconciler's Git executable and Git/loader configuration were inherited from the caller rather than fixed by the reviewed source. Actual exploitability through approved CI is unknown.
- **failedApproach:** Treating a syntactically valid SHA and a zero exit status from whichever `git` was on PATH as sufficient local evidence ancestry.
- **correction:** [`642b2949`](https://github.com/m-shogo/memories-project/commit/642b2949195db7dfee9a58f34e1b44f77e4c07c2) pins both reconciler ancestry calls to `/usr/bin/git`, strips `GIT_*`, `LD_*` and `DYLD_*` inherited variables, disables replacement objects and ambient Git config, imposes a 20-second timeout and returns a fail-closed false on OSError or TimeoutExpired.
- **recurrenceGuard:** The existing CI-reached backup authority atomic negative suite now runs the established actual-Git positive, fake-PATH-Git negative and sanitized-environment subprocess spy against all three callers: local foundation, backup normalizer and coherent recovery. The fake `git` is proven to return success for a fabricated SHA before each guarded caller must reject that SHA.
- **retryCondition:** Revisit only if the reviewed Git executable/runner environment changes, a source-ancestry implementation changes, or exact-source CI proves a regression. Do not retry unchanged Quay MinIO HTTP 401, workflow permission or missing external/human production-evidence blockers.
