## Material failure — prospective computed-attribute binding bypass

- **Symptom:** A module-level `attribute = "main"; setattr(sys.modules[__name__], attribute, None)` can replace the checked `main` callable before the canonical module guard, while `attribute = "validate_learning_guards"` can replace the learning validator binding. The prewrite checker likewise could admit `setattr(module, attribute, None)` or `delattr(module, attribute)` despite a unique synchronous `main` definition.
- **Observed evidence:** At reviewed source `0555962d7e4b39d2f13b334e12ffa1c04ad8fa8d`, both `module_scope_rebinds` and `module_shadows_main` rejected `setattr`/`delattr` only when the second argument was a literal equal to the protected name. A computed attribute name was ignored. This is a prospective static guard gap, not observed CI compromise or a production incident.
- **Verified root cause:** The lexical protected-binding check treated a non-constant attribute name as unrelated, although its runtime value may equal `main` or `validate_learning_guards`.
- **Failed approach:** Using literal-name equality as a complete proof for reflective attribute mutation.
- **Correction / executable recurrence guard:** [`f6653113`](https://github.com/m-shogo/memories-project/commit/f66531135027f28f1bc60b06b6aed3fefe3eb7c6) conservatively rejects non-constant `setattr`/`delattr` names in the module-scope protected-binding and prewrite checks. Four canonical exact-diagnostic negatives cover dynamic main/learning-guard mutations; two nested prewrite negatives cover computed main mutation/deletion. Positive controls retain constant unrelated attribute mutation. The first canonical diagnostic for computed learning-guard mutation is correctly bound to the earlier conservative `main` check.
- **Retry condition:** A legitimate computed attribute mutation requires reviewed receiver/name resolution and binding proof, changed preconditions, exact-source CI, bounded prewrite, correct diagnostic, CAS and protected-authority verification. Arbitrary alias/reflection closure is not claimed.
