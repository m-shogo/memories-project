## Material failure A — pathname publication could cross a swapped parent

- **symptom:** After staged bytes and a bounded final leaf/ancestor check, the Upload Route atomic writer still used `os.replace(temporary, path)`. A parent directory renamed and replaced by a symlink at the replace syscall could redirect publication outside the reviewed authority tree. This was a source-verified latent race, **not** an observed production overwrite.
- **evidence:** At initial `so` `a1b6af02df505cbd805f2c209d948a3d6d7a01b0`, `scripts/reconcile-memory-os-upload-route-authority.py` performed pathname `os.replace` after final preflight. Prior supplemental lessons `2026-10-31-upload-route-poststage-target-drift-ci.md` and `2026-10-31-upload-route-pinned-new-file-unlink-parent-swap.md` explicitly left write-side publication parent pinning unresolved.
- **rootCauseOrUnknown:** Verified: a bounded pathname precheck is not a directory capability and cannot bind a later pathname rename to the inspected parent. No actual production race or external canary overwrite was observed.
- **failedApproach:** Treating final pathname existence/inode/byte checks plus atomic rename as sufficient parent-path protection.
- **correction:** [`13987f56`](https://github.com/m-shogo/memories-project/commit/13987f56d21c5dd459e75fb8f2546aabed86c6e2) requires `O_DIRECTORY|O_NOFOLLOW`, opens and compares the pinned/live parent device and inode, compares the staged inode and leaf via `dir_fd`, publishes with `os.replace(temporary.name, path.name, src_dir_fd=parent_fd, dst_dir_fd=parent_fd)`, rechecks the live parent, and cleans staged names via pinned `os.unlink(..., dir_fd=parent_fd)`. Missing directory safety flags fail closed.
- **recurrenceGuard:** The same commit adds a disposable real-filesystem negative that renames the parent and symlinks it to an external directory **at the actual replace call**, plants a matching external temporary-name decoy and an external destination canary, and requires both to remain byte-identical. It also tests unsupported `O_DIRECTORY`. The existing pre-MinIO entrypoint binds the live proof, the descriptor-relative source, and deterministic weakening mutations. Exact-source [Autonomous Learning Guard #41192531475](https://github.com/m-shogo/memories-project/actions/runs/41192531475) completed SUCCESS after the scoped fixture corrections below.
- **retryCondition:** Revisit on changed atomic writer, staged-file ownership, parent/leaf race semantics, platform directory-fd support or exact-source CI. **This is not atomic leaf CAS**: an uncooperative writer can still swap the leaf between stat and rename. A parent swap during the rename can leave an owned file modified in a renamed original directory before the post-publication drift rejection; complete transactional rollback and pre-acquisition temporary cleanup remain separate review targets.
