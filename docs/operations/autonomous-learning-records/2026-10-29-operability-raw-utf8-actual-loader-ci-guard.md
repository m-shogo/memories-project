## Material failure: symptom, evidence, root cause, failed approach, correction, guard, retry

- **Symptom:** The production-operability validator's self-test named `invalid UTF-8` used ASCII bytes containing the invalid JSON escape `\\xff`, not an actual invalid UTF-8 byte. Thus that label did not independently prove the decoder's raw-byte failure path.
- **Observed evidence:** `scripts/validate-memory-os-operability.py` defines the mislabeled case as `b'{"x":"\\\\xff"}'`. The actual loader already calls `raw.decode("utf-8")` and catches `UnicodeError`; no evidence of accepting malformed UTF-8 was observed. Prior supplemental learning explicitly recorded this test-quality gap and the known 79-workflow fanout of editing that shared validator.
- **Verified root cause:** A JSON escape rejection fixture was mislabeled as a UTF-8 decoding negative. The existing successful validator run proved rejection of that input, not rejection of an invalid byte.
- **Failed approach:** Treating a backslash-x JSON escape as equivalent to raw invalid UTF-8, or editing the 79-workflow-fanout validator solely to fix the label while known CAS/MinIO blockers remained unchanged.
- **Correction:** [6e4448ae](https://github.com/m-shogo/memories-project/commit/6e4448ae4d6c260316a6768bd34760ba65095395) adds an independent CI-reachable actual-module probe to `scripts/validate-memory-os-entry-docs.py` without changing the high-fanout source. The probe first verifies a valid JSON object is accepted, then writes byte `0xff` into a JSON string, confirms that payload itself cannot decode as UTF-8, and requires the actual `load_json` implementation to raise its canonical `ValidationFailure`.
- **Executable recurrence guard:** The existing Autonomous Learning Guard runs the entrypoint on exact source, and the new test fails if the operability module is missing, cannot load, fails its positive control, or accepts the raw malformed byte. The temporary fixture is outside the repository and does not modify production status.
- **Retry condition:** Revisit when the operability JSON loader, source CI reachability, or UTF-8 validation policy changes. Do not retry unchanged Quay MinIO HTTP 401, canonical learning large-file HTTP/2 transport, or a known stale-source writer.
