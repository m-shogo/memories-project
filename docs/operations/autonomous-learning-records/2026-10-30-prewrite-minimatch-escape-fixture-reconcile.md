## Material defect / failure

- **symptom:** The read-only prewrite fanout audit could undercount plain YAML path filters containing a backslash. During its test addition, a generated string replacement also silently **removed** the pre-existing `brace glob` fixture in each of two test suites while both CI jobs still reported SUCCESS.
- **evidence:** [`d1a6ece0`](https://github.com/m-shogo/memories-project/commit/d1a6ece0f7253056b2d47f14d0fb8ded7691cd71) added two plain-backslash fixture labels but replaced the original brace-glob anchor. Source re-read confirmed `brace glob` was absent in both case inventories. Python `fnmatch.fnmatchcase("scripts/a.py", r"scripts/\\a.py")` does not match, so treating a GitHub minimatch escape as a Python literal can undercount.
- **rootCauseOrUnknown:** Verified code-generation mistake: replacement used `replace(anchor, insertion)` instead of `replace(anchor, insertion + anchor)`, discarding the original case. The backslash semantics mismatch is independently visible in the prior `fnmatch` parser.
- **failedApproach:** Adding tests by unguarded textual anchor replacement and accepting a green CI job as proof that all historical fixtures were preserved.
- **correction:** [`a5b6c595`](https://github.com/m-shogo/memories-project/commit/a5b6c5954cd589331eb6c47d94de4d08849d639a) restores both `brace glob` fixtures and pins exact ordered case-label identities and expected counts in both suites. The read-only auditor conservatively classifies any backslash-bearing positive pattern as potentially matching instead of delegating ambiguous escape semantics to Python `fnmatch`.
- **recurrenceGuard:** The executable self-test and real-CLI negative suite now verify their **39** and **22** exact ordered fixture identities with SHA-256 digests, not just total case counts. Equal-count substitutions, including accidentally deleting `brace glob`, now fail CI unless the reviewed identity baseline is explicitly reconciled.
- **retryCondition:** Future fixture additions must insert without deleting the anchor, verify exact old/new ordered label sets before write, run the real CLI against the changed source, and update pinned digests only with reviewed fixture changes. Do not repeat the original unguarded replacement. Existing MinIO 401, canonical large-learning transport and human-approval blockers remain unchanged and must not be retried without new preconditions.
