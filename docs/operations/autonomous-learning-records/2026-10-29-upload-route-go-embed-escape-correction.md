## Material failure / guard-fixture quality

- **Symptom:** The first generated Go embed guard contained double-escaped Python `\\t` and `\\n` sequences in a raw regex and synthetic fixtures. That form could accidentally accept a backslash in place of an actual tab and create literal backslash-n fixture bytes instead of a newline.
- **Observed evidence:** [4fc06c3f](https://github.com/m-shogo/memories-project/commit/4fc06c3f9f164731a451d326f12b0376c514dbae) was immediately inspected by fetching the exact written source; the inserted block contained doubled escapes. The first [CI #40885723152](https://github.com/m-shogo/memories-project/actions/runs/40885723152) ultimately returned SUCCESS, which **does not** prove the intended tab/newline semantics of the flawed fixture. No production incident was observed.
- **Verified root cause:** JavaScript template literal escaping was applied twice when generating Python source, changing the regex character class and fixture string semantics.
- **Failed approach:** Treating visually plausible escaped source text and a green CI negative suite as proof of exact intended Python escape semantics.
- **Correction:** [a2706ad9](https://github.com/m-shogo/memories-project/commit/a2706ad9838935c81b90a1957b05ac53673cb361) repaired the exact inserted block, converting doubled backslashes to single Python escape sequences, and re-read the serialized result before relying on CI.
- **Recurrence guard:** The read-only Go import closure now rejects `//go:embed` directives in both target and visited local Go sources, with three synthetic rejection cases and a positive non-directive control. Exact-source CI is the executable check. A distinct tab-byte fixture is still required to prove the specific escape-class regression and remains the next safe target; do not claim that proof yet.
- **Retry condition:** Recheck literal tab/newline semantics after any cross-language source generation or Go embed guard change. Do not retry unchanged Quay MinIO HTTP 401, canonical learning large-file append, workflow-write permission or human promotion blockers.
