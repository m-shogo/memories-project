- **evidence:** At baseline `0020a92040c211aca590f55d6832dbd89a13ecf1`, `scripts/validate-autonomous-learning-system.py` rejected world-writable in-repository ancestor directories (`0o002`) and group-writable leaf authorities (`0o020`), but did not reject group-writable ancestor directories. Existing CLI negatives covered four world-writable ancestor locations, not group-writable ones. This was a prospective path-replacement authority gap, not an observed production incident.
- **rootCauseOrUnknown:** Verified incomplete parent permission predicate: the parent check considered other-write but omitted group-write. The affected authority ancestors are the checkout root, `scripts`, `contracts`, `contracts/operations`, `docs` and `docs/operations`.
- **failedApproach:** Treating world-writable parent rejection and group-writable leaf rejection as equivalent to complete parent replacement protection.
- **correction:** [`9771e94e`](https://github.com/m-shogo/memories-project/commit/9771e94e9af771821e137328254b721838726e58) adds a separate fail-closed `0o020` parent check while retaining the original world-writable diagnostic priority. Four initial real-CLI group-writable parent negatives were added. [`b1c2033e`](https://github.com/m-shogo/memories-project/commit/b1c2033e5572597617c71bf556ca72e63546621e) extends both world/group parent negative inventories to all six actual canonical ancestor paths (four additional CLI negatives).
- **recurrenceGuard:** Actual CLI negatives use disposable checkout trees with `0o775` group-writable and `0o777` world-writable ancestors; exact diagnostic assertions must reject both, while clean canonical positive controls continue to pass. The descriptor reader already checks parent inode/mode/ctime changes during a read. This is mode-bit enforcement, not a proof of all external filesystem/ACL attack surfaces.
