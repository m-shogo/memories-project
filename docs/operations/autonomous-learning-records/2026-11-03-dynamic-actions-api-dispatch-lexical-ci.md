- **rootCauseOrUnknown:** Verified per-invocation tool-call ceiling; the exact configured numerical ceiling is unknown.
- **failedApproach:** An unbounded concurrent fetch loop, followed by another oversized single-invocation batch, cannot serve as complete evidence.
- **correction:** Split immutable Git-tree blob reads into bounded batches of at most 14 blobs per invocation; re-fetch the same immutable tree identity for each batch and collect only aggregate findings.

- **retryCondition:** Reconsider larger batches only if the connector's documented per-invocation call capacity changes.
