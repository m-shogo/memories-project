## Material failure — local foundation source ancestry trusted inherited PATH

- **symptom:** `scripts/validate-memory-os-backup-local-foundations.py` accepted a successful bare `git merge-base --is-ancestor` process exit as source ancestry. Inherited PATH could resolve `git` to an executable returning 0 for an invented 40-hex SHA. This is a local foundation evidence-integrity weakness, not observed production evidence fabrication.
- **evidence:** At prior source blob `1dbd9743`, `source_is_ancestor()` launched `["git", "merge-base", ...]` without sanitizing inherited Git or loader variables. An isolated PATH-first shell decoy returned exit 0 for `"0"*40`, while the reviewed `/usr/bin/git` returned exit 128 for the same synthetic SHA outside a Git checkout. This demonstrates executable-resolution spoofing, not actual compromise of the repository or runner.
- **rootCauseOrUnknown:** Verified PATH-based executable selection and inherited environment trust. Whether a real attacker controls runner PATH is unknown.
- **failedApproach:** Checking only the 40-hex SHA syntax and subprocess return code while allowing inherited executable lookup and Git/dynamic-loader overrides.
- **correction:** [`308cce5b`](https://github.com/m-shogo/memories-project/commit/308cce5ba077cacafbb1b754c8d41dedf10a7e6d) pins the Git executable to `/usr/bin/git`, strips `GIT_*`, `LD_*`, `DYLD_*`, sets no-replace/system/global-config overrides and bounds the Git subprocess to 20 seconds. Existing local-only validation and `NO_GO` checks remain unchanged.
- **recurrenceGuard:** [`2ca817cc`](https://github.com/m-shogo/memories-project/commit/2ca817cc2d261b3c6b3b180d2d877b91021fef63) extends the existing CI-reachable backup authority atomic negative suite. It first verifies a real current-HEAD positive ancestry, then proves a disposable PATH-first decoy returns false success while the live validator rejects the invented SHA. A separate mocked call verifies the pinned binary, sanitized `GIT_DIR`/`LD_PRELOAD`/`DYLD_INSERT_LIBRARIES` and Git no-replace/global-config overrides. PATH and subprocess mocks are restored; the decoy resides only in a temporary directory.
- **retryCondition:** Revisit if the reviewed runner lacks a trusted `/usr/bin/git`, source ancestry semantics or Git subprocess arguments change, or exact-source CI regresses. Do not retry unchanged external Quay MinIO HTTP 401, workflow-write permission or human production-evidence blockers.
