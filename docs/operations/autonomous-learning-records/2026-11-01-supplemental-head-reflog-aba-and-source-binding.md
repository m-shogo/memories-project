## Material failure risk A — an A → B → A HEAD transition evades an OID-only audit

- **symptom:** A mutable local HEAD can move from the initially audited commit to another commit and back while the all-parent history checker traverses its captured OIDs. Identical before/after OIDs alone cannot detect this. This was a source-verified latent proof gap, **not an observed production or repository history rewrite**.
- **evidence:** Starting `so` `13d0666ab73ed18e4203154142e0490db5291eec` had a final `HEAD^{commit}` comparison but no reflog witness. An isolated real-Git probe observed identical final HEAD after two `update-ref` transitions while the local HEAD reflog size and metadata changed. The new disposable self-test injects the same transition during `rev-list --reverse`.
- **rootCauseOrUnknown:** Verified that an OID identity comparison is not a temporal ref-change witness. The local reflog is a bounded diagnostic, **not** an atomic ref lease, tamper-proof proof, remote branch audit or independent production authority; Git itself remains trusted.
- **failedApproach:** Treating a stable initial/final HEAD OID as proof that no intermediate ref movement occurred.
- **correction:** [`16cd3209`](https://github.com/m-shogo/memories-project/commit/16cd3209bfa01fcf0048471d956f706ec5b57bf6) records the device/inode/size/mtime/ctime of the local HEAD reflog before traversal, rechecks it after traversal and rejects drift with a fixed failure class. It rejects missing, malformed, symlinked or nonregular reflog witnesses without falling back to an OID-only success.
- **recurrenceGuard:** A real-Git A → B → A negative and recovery positive run in the existing pre-MinIO supplemental history self-test. Missing and symlinked reflog negatives are added below. The CI entrypoint binds the live helper and before/after check with independent AST and source weakening mutations.
- **retryCondition:** Revisit if Git reflog semantics, detached/linked worktree behavior, local checkout/ref model, helper source, CI reachability or a new observed ABA bypass changes. Do not claim an atomic CAS or retry unchanged external/permission blockers.
