## Material failure / verified static Go import-closure gap

- **Symptom:** A legal Go import declaration placed after an explicit semicolon (`package p; import "..."`) or after an inline block comment (`/* note */ import "..."`) could be omitted from the Upload Route Go local dependency closure without raising an error.
- **Observed evidence:** The previous `upload_route_local_go_imports` recognized only line-anchored `import` declarations. A minimal reproduction returned an empty local-import set for a valid `package p; import "github.com/m-shogo/memories-project/services/import-api/internal/metrics"` source. Local `gofmt` accepted both semicolon-prefixed and block-comment-prefixed import forms and normalized them into separate lines. This is a static parser undercount, **not** observed production Go usage.
- **Verified root cause:** Line-anchored Go import discovery did not reject legal declaration placements with earlier tokens on the same line. Counting only parsed imports could silently omit a transitive local package.
- **Failed approach:** Assuming every valid Go import begins at the start of its own line or that unparsed declarations are necessarily invalid Go syntax.
- **Correction / executable recurrence guard:** [8a5cefac](https://github.com/m-shogo/memories-project/commit/8a5ceface76feef7f7dd0acab5ef99dbffee38d8) rejects semicolon- and block-comment-prefixed `import` declarations before the reviewed line-anchored parser runs. Two synthetic negatives require the exact `unreviewed Go import placement` diagnostic. Existing positive block and single-line import fixtures remain mandatory.
- **Limitations:** This conservative lexical guard does not implement a complete Go lexer/parser, account for all possible comment/string syntaxes, or prove external module/native/toolchain or full CI trigger closure. Upload Route Publisher/PR filters were not changed.
- **Retry condition:** Re-review legitimate import syntax or dependency-graph changes with a real Go parser/toolchain comparison, exact source input-set identity, positive and negative fixtures, exact-source CI, and protected-authority check.
