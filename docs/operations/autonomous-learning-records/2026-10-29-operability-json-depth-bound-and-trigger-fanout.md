## Material failure: symptom, evidence, cause, failed approach, correction, guard, retry

- **Symptom/evidence:** The existing production-operability JSON reader bounded input bytes and rejected duplicate/nonfinite JSON, but had no explicit 128-digit integer or 64-level nesting limit. In a local disposable synthetic probe, a 1200-level nested JSON array was accepted by the active Python decoder, so relying on an assumed decoder recursion ceiling was not a deterministic guard. No actual production incident or evidence forgery was observed.
- **Verified root cause:** Decoder recursion limits depend on runtime; default integer parsing does not enforce this application's reviewed 128-digit bound. The earlier canonical 2026-10-26 learning already documented broad 79-workflow fanout for edits to this shared validator and an existing actual-module parser negative suite.
- **Failed approach:** Assuming Python's default recursion limit reliably rejects deep JSON, and changing a high-fanout shared validator before a cross-workflow trigger audit. The latter repeated an already documented high-fanout failure class.
- **Correction:** [c1c245db](https://github.com/m-shogo/memories-project/commit/c1c245dbc64322577d2eb38a1ad4d5405f0576c0) added a bounded string-aware JSON nesting scanner, a 128-digit integer parser, RecursionError classification and 10 executable synthetic negative cases plus a positive control. The implementation remains read-only; its actual loader runs before the operability status validation.
- **Executable recurrence guard:** The new depth and integer negatives run through the actual loader in `scripts/validate-memory-os-operability.py`. Separately, the later CI-bound prewrite fanout audit flags shared validator edits as high-risk before another broad push. The earlier actual-module negative suite remains separate and should not be counted as new proof.
- **Retry condition:** Revisit only on an observed parser regression or reviewed input policy change, and perform the prewrite fanout audit first. Do not blindly rerun 79 previously triggered workflows, stale CAS failures, or the unchanged Quay MinIO HTTP 401.
- **Residual test-quality gap:** The newly labeled `invalid UTF-8` self-test currently uses a backslash-x JSON escape rather than a raw invalid UTF-8 byte. It still exercises rejection, but must not be claimed as independent UTF-8 negative proof. The earlier controlled-saturation actual-module suite has a genuine raw-byte negative; this run's corresponding workflow failed before executing it due source-head drift. Correct the mislabeled self-test only with a scoped, CI-reachable change that does not recreate the known 79-workflow blast radius.
