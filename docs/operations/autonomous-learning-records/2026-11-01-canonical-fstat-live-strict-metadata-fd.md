## Material failure class

- **symptom:** A synthetic descriptor-pinned `fstat` or post-read leaf `lstat` result with a boolean/int-subclass metadata field could be classified or compared as a valid integer snapshot, or yield a generic drift diagnostic instead of the exact unreadable-authority rejection. This is a source-level fault-injection gap, not an observed production incident or claim that CPython normally returns malformed stat metadata.
- **evidence:** At previous HEAD `194ccd43`, strict metadata checks existed for preflight leaf and ancestor snapshots and the post-read ancestor, but `before=os.fstat(fd)`, `after=os.fstat(fd)` and `live=path.lstat()` used mode, device, inode, link count, size and timestamps directly without exact built-in integer checks. In particular `True == 1` and a directory/file mode `int` subclass preserves the same `stat.S_IFMT` classification.
- **rootCauseOrUnknown:** Verified inconsistent strict metadata validation across canonical reader snapshot boundaries. Real OS-returned malformed stat occurrence is unknown and not asserted.
- **failedApproach:** Assuming regular-file classification, numeric equality and a final metadata comparison are equivalent to validating the exact type of every field used for canonical authority.
- **correction:** [`2d7f594c`](https://github.com/m-shogo/memories-project/commit/2d7f594c1a42113437f018860e0e0a5e5c33fb55) enforces exact built-in `int` for `st_mode`, `st_dev`, `st_ino`, `st_nlink`, `st_size`, `st_mtime_ns` and `st_ctime_ns` at descriptor `before`, descriptor `after` and live-leaf snapshots.
- **recurrenceGuard:** [`df9aed17`](https://github.com/m-shogo/memories-project/commit/df9aed1761df442e00b39d1cde12dff3b6bec4d6) adds six CI-bound fault-injection negatives: before/boolean mode, before/boolean link count, after/boolean link count, after/string ctime, live/integer-subclass mode and live/string inode. Each requires the exact unreadable diagnostic, precise first/second `fstat` and leaf-`lstat` reachability, exactly one owned FD, EBADF after cleanup, external FD canary preservation and a subsequent positive read.
- **retryCondition:** Revisit when the descriptor/leaf stat field inventory, read order, FD ownership or observed malformed return class changes. Do not retry unchanged MinIO HTTP 401, workflow-write permissions or absent human production-evidence prerequisites.
