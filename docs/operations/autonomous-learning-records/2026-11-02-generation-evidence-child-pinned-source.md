## Material failure — reviewed child source reopened by mutable pathname

- **symptom:** The generation-evidence validator allowed a reviewed child script to be re-opened by the child Python interpreter after an earlier pathname admission. A post-check swap could change the executed source; this is a verified source-level TOCTOU gap, not an observed exploit or production incident.
- **evidence:** At pre-change `81b6969fefb14184628f08550722c984510eea25`, `run_validator` checked `require_exact_repo_file` but executed `subprocess.run([sys.executable, str(path)], ...)`. The writer importer already had descriptor-pinned, no-follow, size/mode/identity-checked source acquisition. Prior related learning: `2026-11-02-drill-request-validator-pinned-helper-import.md` and `2026-11-01-upload-route-stage-entropy-and-collision-retry.md`.
- **rootCauseOrUnknown:** Verified: direct child interpreter pathname reopening was not bound to the source checked by the parent. Whether an actual adversary changed this path during a production run is unknown; no such event is claimed.
- **failedApproach:** Treating a label/path allowlist and one-time `require_exact_repo_file` as sufficient to bind the later interpreter's source read.
- **correction:** [`5e0a1197`](https://github.com/m-shogo/memories-project/commit/5e0a119728632b69c69f0cc0d4a827e2e86d9f7b) generalizes the existing descriptor-pinned writer source reader and passes its reviewed bytes to the child Python bootstrap through stdin, preserving direct-script `__name__`, `__file__`, `sys.argv`, and sibling import path semantics. Existing label/path allowlist, environment isolation, private output and 90-second deadline remain.
- **recurrenceGuard:** [`9d11ed75`](https://github.com/m-shogo/memories-project/commit/9d11ed750db6af566a1fe18f14a9c06d345688ef) updates the existing CI-reachable generation-evidence load-negative suite: all four approved child labels must receive their exact source bytes through stdin; a real temporary-directory pathname swap during pinned `os.read` must be rejected before subprocess launch. The corresponding workflow includes both changed scripts in its push path filters and invokes this suite. Exact-source CI outcome was **not observable from the available read API at record time**; do not promote source-level assertions to an executed PASS.
