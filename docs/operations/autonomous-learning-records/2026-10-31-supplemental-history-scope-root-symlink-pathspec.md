## Material failure class: symptom, evidence, rootCauseOrUnknown, failedApproach, correction, recurrenceGuard, retryCondition

- **symptom:** The all-parent supplemental history checker did not inspect a newly added symlink whose path was *exactly* a protected learning-scope directory root. This is a static history-guard gap, not observed production corruption.
- **evidence:** A disposable Git repository with an existing `docs/operations/autonomous-learning-records/original.md` and a newly committed symlink `docs/operations/autonomous-learning-addenda -> autonomous-learning-records` showed that `git diff-tree -r --name-status BASE HEAD -- docs/operations/autonomous-learning-addenda/` emitted **no entry**, while the same command without the trailing slash emitted `A docs/operations/autonomous-learning-addenda`. The old `check_history` used trailing-slash pathspecs.
- **rootCauseOrUnknown:** Verified: Git pathspecs ending in `/` select descendants, but omit a symlink at the directory-root pathname. The prior per-entry prefix check was fail-closed only for paths that the Git command actually returned.
- **failedApproach:** Using protected directory prefixes with trailing slashes as the Git diff pathspecs and assuming this covered changes to the scope root itself.
- **correction:** [Code commit 8455d39e](https://github.com/m-shogo/memories-project/commit/8455d39ec5339ba0ed39f00499ec297bf5c39bc2) removes the trailing slash **only for the Git pathspec**; the existing `path.startswith(scope + "/")` admission check remains strict, so the root symlink is rejected instead of being accepted as an added learning record.
- **recurrenceGuard:** A deterministic, cause-specific `scope-root-symlink` negative fixture creates the actual Git symlink and requires `supplemental history is not append-only`. The CI-bound entrypoint now requires the exact 33-fixture PASS line (formerly 32).
- **retryCondition:** Revisit if reviewed protected scope roots, Git diff pathspec construction, history traversal, or executable CI binding change. Do not repeat the trailing-slash-only pathspec approach without a changed precondition. Do not retry unchanged workflow-write, MinIO HTTP 401, canonical learning large-file transport, or human approval blockers.
