## Material failure A — Git metadata accepted after lossy normalization

- **symptom:** The supplemental history checker stripped and split successful Git stdout before interpreting HEAD OIDs, commit enumeration and parent enumeration. Whitespace, extra lines and malformed types could be normalized or fail indirectly rather than rejected for their actual cause. This was a source-verified guard gap, not an observed production-history rewrite.
- **evidence:** At starting HEAD `d9a70282`, `scripts/validate-autonomous-learning-records-history.py` used `.stdout.strip().decode("ascii")`, `.splitlines()` and `.split()` for those commands without exact successful-output grammar. [`2a7fef47`](https://github.com/m-shogo/memories-project/commit/2a7fef473aa4c986fa60263cf660b20cc593f33d) introduced a wrapper guard and synthetic negatives, but immediate post-write source inspection found doubly escaped Python regex/fixture newline spellings. This intermediate commit was **not** verified by exact-source CI.
- **rootCauseOrUnknown:** Verified missing exact stdout validation before lossy normalization. The first correction attempt also used double escaping when composing Python source through a JavaScript string.
- **failedApproach:** Relying on caller-side strip/split and constructing backslash-sensitive regex/fixture strings without inspecting the published source spelling.
- **correction:** [`df69cc2e`](https://github.com/m-shogo/memories-project/commit/df69cc2ee2d4be4b3d568d00b23e76206e2797cd) corrected parsed newline/tab/NUL literal spellings. The wrapper now rejects malformed successful `HEAD^{commit}`, `rev-list --reverse` and `rev-list --parents -n 1` output before callers can normalize it.
- **recurrenceGuard:** The executable `--self-test` injects 17 malformed successful stdout values (including non-bytes) and requires three valid transport positives. The CI-reachable entrypoint independently checks the live `git()` AST tail, three byte regex grammars, three exact rejection reasons and three byte-type guards, then mutates the reviewed source to prove rejection.
- **retryCondition:** Revisit only if the Git hash algorithm, Git output grammar, Git command call shape or history checker changes. Do not retry an unchanged external/permission blocker.
