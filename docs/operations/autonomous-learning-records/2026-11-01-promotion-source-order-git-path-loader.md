## Material failure — promotion chronology still used inherited Git executable/environment

- **symptom:** The human promotion review source-order validator used bare `git` for history, creation blob, commit existence and ancestry, inheriting PATH, Git and dynamic-loader overrides. A PATH-first executable could forge a syntactically valid creation SHA or ancestry result without an actual reviewed human promotion.
- **evidence:** At source blob `2ed0da5f`, four subprocess call sites used `["git", ...]` with no sanitized `env`. The existing `--self-test` checked chronology semantics but did not execute a PATH-decoy transport negative. No actual forged review, malicious runner or production promotion was observed.
- **rootCauseOrUnknown:** Verified inherited executable and environment trust boundary. Whether an adversary controls the runner remains unknown.
- **failedApproach:** Treating the presence of a reviewed workflow, strict promotion review fields and semantic chronology tests as sufficient proof of Git executable identity.
- **correction:** [`396d1c41`](https://github.com/m-shogo/memories-project/commit/396d1c41d8f4be357aab6c3af18cba9415f23158) pins `/usr/bin/git` for all four subprocess call sites, strips inherited `GIT_*`, `LD_*` and `DYLD_*`, and explicitly disables Git replace objects and system/global config. The human promotion review authority and source-before-review semantics remain unchanged.
- **recurrenceGuard:** The existing CI-invoked `--self-test` now creates a disposable PATH-first fake Git that must first emit a valid forged SHA; the live creation lookup must reject the nonexistent synthetic review for the exact expected reason. A mocked `GIT_DIR`/`LD_PRELOAD`/`DYLD_INSERT_LIBRARIES` call verifies the pinned binary and actual sanitized subprocess environment. Disposable state is restored; no workflow or protected authority is written.
- **retryCondition:** Revisit if reviewed runner Git location, human promotion chronology, source-order invocation or CI changes, or exact-source regression occurs. Do not retry unchanged Quay MinIO HTTP 401, workflow-write permission or human production evidence blockers.
