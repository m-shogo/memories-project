## Material failure class

- **symptom:** A synthetic second ancestor `lstat` result with an integer-subclass directory mode could pass the post-read equality comparison despite lacking an exact built-in integer metadata interface. Other malformed field types could produce a generic canonical-drift diagnostic rather than the strict unreadable-authority diagnostic. This is an observed source-level validation gap, not a reported production incident or ordinary CPython stat failure.
- **evidence:** At prior HEAD `09663dd3`, the reader enforced exact integer types on the initial ancestor snapshot, but the second ancestor `lstat` result was used directly in `stat.S_IFMT`, `stat.S_IMODE` and tuple equality without exact-type checks. The prior post-read negative fixture covered `None` and `object()`, not forged directory-looking mode/identity fields. A local Python 3 check confirms that `stat.S_ISDIR(int_subclass(directory_mode))` is true and `stat.S_IFMT` preserves the same file-type bits.
- **rootCauseOrUnknown:** Verified asymmetry between pre-open strict ancestor metadata validation and post-read ancestor metadata validation. Real OS stat objects remain expected to carry built-in integers; occurrence of malformed real OS-returned objects is unknown and not asserted.
- **failedApproach:** Relying on tuple equality and `stat.S_IFMT`/ `stat.S_IMODE` to validate the post-read metadata type, or treating prior `None`/missing-mode negatives as complete proof.
- **correction:** [`73637a45`](https://github.com/m-shogo/memories-project/commit/73637a45e1fe23d11793854e382416306cc38fd6) requires exact built-in `int` for post-read ancestor `st_mode`, `st_dev`, `st_ino` and `st_ctime_ns` before comparing the ancestor snapshot.
- **recurrenceGuard:** [`4524f8d6`](https://github.com/m-shogo/memories-project/commit/4524f8d660070902e5012dcc1017d1991bdf55a1) expands the existing direct-reader second-`lstat` fixture from two to seven malformed cases: `None`, opaque object, boolean mode, integer-subclass directory mode, missing device identity (`None`), string inode identity and boolean ctime. Each requires exact unreadable-authority rejection, exactly two ancestor reads, exactly one acquired leaf FD, EBADF after cleanup, untouched external FD canary and subsequent valid-read recovery.
- **retryCondition:** Revisit on a changed post-read ancestor metadata interface, identity field inventory, cleanup/FD ownership semantics, or newly observed malformed stat return. Do not repeat unchanged MinIO 401, workflow-write permission or missing human evidence attempts.
