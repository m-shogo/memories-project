# Core Concept

## サービスの正体

このサービスは、ChatGPT や Claude の代わりではない。

相談AIではなく、**自分の人生の文脈を持ち続ける記憶体**を作るサービス。

AIを育てるのではない。

**自分の記憶体を育てる。**

## キャッチコピー候補

- AIは進化する。あなたの人生は引き継がれない。
- AI時代、自分という文脈を持ち続ける。
- 人生の断片を、未来のAIへ渡せる形にする。
- あなたの人生を、どこに置き忘れてきましたか？
- 保存するのはログではなく、あなた自身の文脈。

## この子の役割

記憶体は、ユーザーの代わりに会話し続ける存在ではない。

役割は以下に限定する。

- 覚える
- 整理する
- つなぐ
- 探す
- 比較する
- 思い出させる

長時間チャットや雑談を主目的にしない。

## キャラクターの位置づけ

キャラクターは主人公ではない。

キャラクターは **器**。

中身はユーザーの記憶。

最初はドットキャラ。かわいい。怖くない。相談AI感を出さない。

キャラに人格を盛りすぎると Character.AI に寄ってしまうため、あくまで「記憶の引き出しを持つ存在」として扱う。

## 人生の引き出し

記憶体は、以下のような引き出しを持つ。

- 人物
- 趣味
- ゲーム
- 投資
- 結婚
- 家族
- 学校
- 旅行
- 価値観
- 悩み
- 仕事
- 好み
- 判断基準

育つのはキャラクターの戦闘力ではなく、記憶の引き出し。

例:

最初はゲーム引き出しに「Unity」しかない。

数年後には、Unity、Godot、Steam、ドット絵、発売、レビュー、失敗、改善、思想が自然に増えていく。

## 一番価値がある体験

### 妻ってどんな人？

単に「妻」という単語を検索するだけではない。

人物引き出し、旅行、プロポーズ、結婚式、日常、好み、会話の傾向を横断して答える。

### 去年の俺ならどう思う？

現在のAI知識ではなく、特定時期の記録だけを検索して、当時の考えに近い答えを出す。

重要なのは「正しい答え」ではなく、**当時の自分に近い考え**であること。

### 親ならなんて言う？

ここは強いが、扱いを間違えると人格AIや死者の再現になる。

正しい位置づけは、親を演じることではなく、**親が残した文脈から考え方を参照すること**。

例:

> お父さんが40代で仕事について話していた記録では、「安定よりも、自分が誇れる仕事を選ぶ」という考えが何度か出ています。当時の考え方を踏まえると、こう考えた可能性があります。

断定しない。

「こう言うはず」ではなく、「残された記録から推測するとこう考えそうだった」とする。

## 死後に残せる価値

死後を前面に出しすぎると終活サービスに見える。

基本は、生きている間に自分を理解するサービス。

ただし、長く使った結果として、家族へ人生の文脈を受け渡せる価値が生まれる。

表現としては以下が良い。

**生きている間は、自分を理解するために使う。残ったときには、大切な人へ人生を受け渡すことができる。**

## ペットではなく記憶体

育成ゲームではない。

毎日餌をあげるサービスではなく、人生の断片に栞を挟むサービス。

ユーザーは365日すべてを覚えたいわけではない。

「あの日は大事だった」「この考えは忘れたくない」という瞬間を残せればよい。

## 最終コンセプト

AI時代、自分という文脈を持ち続けるための記憶体。

AIは変わる。

モデルも変わる。

サービスも変わる。

でも、あなたの人生の文脈だけは、この子が持ち続ける。
