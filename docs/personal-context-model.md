# Personal Context Model

## 目的

このサービスは「情報を保存する」のではなく、ユーザーという人間を理解するための文脈を残す。

そのためには、単なるカテゴリ分類では足りない。

人がどう形づくられるかを、心理学・発達・医療・社会環境の観点から最低限モデル化する。

ただし、このサービスは診断・治療・心理判定を行わない。

扱うのは、ユーザー本人の記録から見える「文脈」「傾向」「変化」「人生の物語」である。

## 参考にする考え方

### 1. Bio-Psycho-Social Model

人は、生物・心理・社会の要因が重なって形づくられる。

このサービスでは、以下を分けて扱う。

- Biological / physical: 体調、睡眠、年齢、病気、体力、感覚
- Psychological: 感情、価値観、欲求、恐れ、自己イメージ、習慣
- Social: 家族、友人、学校、仕事、文化、経済、地域、所属集団

注意:

医療判断はしない。

体調やメンタルに関する記録は高感度データとして扱う。

### 2. Narrative Identity

人は、自分の経験をつなぎ、人生の物語として理解する。

重要なのは、出来事そのものだけではなく、本人がそこに与えた意味。

例:

- ただの旅行ではなく、プロポーズにつながる旅行だった
- ただの失敗ではなく、価値観が変わった経験だった
- ただの趣味ではなく、自分らしさを支える世界だった

このサービスでは、記憶を単発イベントではなく、人生の物語の一部として扱う。

### 3. Autobiographical Memory

自伝的記憶は、その人の自己理解と深く結びつく。

特に重要なのは、以下のような記憶。

- 自己定義的記憶
- 転機
- 強い感情を伴う出来事
- 繰り返し語られる出来事
- 人生目標と関係する出来事
- 今の自分の関心とつながる過去

このサービスでは、すべてのログを残すのではなく、自己理解に関係する記憶を優先する。

### 4. Developmental Context

幼少期・思春期・青年期・成人期など、時期によって形成されるものが違う。

例:

- 幼少期: 安心感、家庭環境、親子関係、基本的な信頼感
- 思春期: 自己イメージ、友人関係、所属、劣等感、得意不得意
- 青年期: 進路、恋愛、仕事観、自立、理想の自分
- 成人期: 結婚、仕事、家族、責任、喪失、継承

記憶は日付だけでなく、「人生フェーズ」としても扱う。

### 5. Risk and Protective Factors

人にはリスク要因と保護要因がある。

ただし、このサービスはリスク診断をしない。

保存するのは、本人理解に役立つ文脈としての要因。

#### Risk Context

- 孤独
- 喪失
- いじめ
- 家庭不和
- 貧困
- 強い失敗体験
- 体調不良
- メンタル不調
- 過度なストレス
- 支援の少なさ

#### Protective Context

- 支えてくれる人
- 好きなもの
- 継続している趣味
- 安心できる場所
- 得意なこと
- 小さな成功体験
- 価値観
- 信念
- 自分を回復させる習慣

リスクだけで人を説明しない。

必ず保護要因も同時に見る。

## Person Contextの主要軸

### 1. Core Values

その人が大事にしているもの。

例:

- 家族
- 自由
- 安定
- 挑戦
- 創作
- 成長
- 思い出
- 誠実さ
- お金
- 評価
- 友情
- 美しさ
- 楽しさ

抽出ルール:

- 何度も出る言葉
- 大きな判断で優先されたもの
- 怒りや悲しみの裏にある大事なもの
- 褒めているもの
- 守ろうとしているもの

### 2. Self Image

本人が自分をどう見ているか。

例:

- 面倒くさがり
- 新しいものが好き
- 継続が苦手
- 家族を大事にしたい
- 完璧にしたい
- 人に頼るのが苦手

注意:

自己イメージは事実ではなく、本人の語り。

断定しない。

### 3. Roles

その人が生きている役割。

例:

- 夫 / 妻
- 親 / 子
- 友人
- エンジニア
- クリエイター
- 投資家
- ファン
- 式を準備する人
- 家族を支える人

役割は時期で変わる。

役割ごとに価値観や悩みも変わる。

### 4. Relationships

人間関係は、その人の人格理解に大きく関わる。

扱う情報:

- 関係性
- 共有した出来事
- よく出る感情
- 支えられた経験
- 価値観の衝突
- 距離感の変化

注意:

他人を診断しない。

「相手はこういう人」ではなく、「ユーザーの記録ではこういう関係として表れている」とする。

### 5. Formative Experiences

その人を形づくった体験。

例:

- 初めて成功した経験
- 強い失敗
- 恥ずかしかった出来事
- 褒められた経験
- 裏切られた経験
- 大きな喪失
- 病気
- 引っ越し
- 受験
- 就職
- 転職
- 結婚
- 出産
- 作品との出会い

抽出ルール:

- 何度も語られる
- 現在の判断に影響している
- 感情が強い
- 人生フェーズの切り替わりにある
- 「あれがあったから」と語られる

### 6. Taste and Affinity

好きなものは、その人を理解するために重要。

例:

- 好きな作品
- 好きな色
- 好きな場所
- 好きな音楽
- 好きなキャラクター
- 好きな雰囲気
- 苦手な表現

好きなものは軽く見えがちだが、長期的にはその人の価値観や安心感に関係する。

### 7. Coping and Recovery

落ち込んだ時、疲れた時、どう戻るか。

例:

- 寝る
- 散歩する
- 音楽を聴く
- ゲームする
- 妻と話す
- 予定を立てる
- 書き出す
- 調べる
- 作る

これはメンタル診断ではなく、その人の回復パターンとして扱う。

### 8. Repeated Patterns

繰り返されるパターン。

例:

- 新しいアイデアに熱中する
- コストや継続性を心配する
- 最初に大きく構想し、あとで現実的に削る
- 品質や安全性を気にする
- 面倒なことは続かないと判断する

繰り返しは人格理解に重要。

ただし、ラベル貼りしすぎない。

### 9. Change Over Time

人は変わる。

記憶体は「今の性格」を固定するのではなく、変化を扱う。

例:

- 2026年は保存や継承への関心が強かった
- 以前は便利さを重視していたが、最近は安全性を重視している
- 昔はゲーム完成が中心だったが、今は人生の文脈を残すことへ関心が広がった

### 10. Future Self

人は過去だけでなく、未来像にも形づくられる。

扱う情報:

- なりたい自分
- 避けたい未来
- いつかやりたいこと
- 守りたい関係
- 残したいもの
- 死後に受け渡したいもの

## 記憶候補の評価基準

MemoryCandidateには、以下の観点でスコアを持たせる。

```ts
type PersonalContextScore = {
  selfUnderstanding: number; // 自己理解に役立つか
  formativeImpact: number; // 形成体験として重要か
  emotionalWeight: number; // 感情の強さ
  repetition: number; // 繰り返し出ているか
  relationshipImpact: number; // 人間関係に関係するか
  valueSignal: number; // 価値観が見えるか
  lifePhaseSignal: number; // 人生フェーズが見えるか
  futureRelevance: number; // 将来見返す価値があるか
  sensitivityRisk: number; // 高感度リスク
};
```

保存優先度は、価値スコアだけでなく、sensitivityRiskも見て判断する。

高価値・高リスクの記憶は自動保存しない。

## やってはいけない推測

### 診断しない

禁止:

- うつ病です
- 発達障害です
- 愛着障害です
- トラウマがあります
- この人は依存傾向です

許容:

- 記録上、この時期は強いストレスを感じていた可能性があります
- この話題は何度も出ており、本人にとって重要だったようです
- この出来事は価値観の変化に関係している可能性があります

### 原因を断定しない

禁止:

- あなたがこうなった原因は親です
- この経験が人格を作りました

許容:

- この経験は、その後の判断基準と関連している可能性があります
- 記録上、この時期から同じテーマが繰り返し出ています

### 他人を評価しない

禁止:

- 父親は冷たい人です
- 妻はこういう性格です

許容:

- あなたの記録では、父親との関係は仕事観に関する話題と結びついています
- 奥様との記憶では、旅行や結婚式準備が多く残っています

## 初回診断への応用

初回診断はMBTI風に見せてもよいが、目的はタイプ分けではない。

目的は、初期のPersonal Context Seedを作ること。

質問カテゴリ:

- 大事にしているもの
- 好きなもの
- 苦手なもの
- 最近考えていること
- 支えになっている人
- 忘れたくない出来事
- 将来残したいもの
- 自分を表す言葉
- 過去の転機
- 未来の自分への不安

結果は「あなたは○○タイプ」と断定しない。

代わりに、以下を生成する。

- 初期プロフィール
- 価値観候補
- 好きな雰囲気
- 記憶の引き出し候補
- キャラクターの見た目
- 話し方の安全な初期設定

## 記憶体の回答スタイル

記憶体は断定しない。

以下のように答える。

- 記録では
- この時期のあなたは
- 何度か出ているテーマとして
- 推測になりますが
- 当時の文脈から見ると

## 参考ソース

- WHO: Mental health is shaped by individual, family, community, and structural factors; risks and protective factors operate at multiple levels.
- WHO: Social determinants of health are the conditions in which people are born, grow, work, live, and age.
- CDC: Adverse Childhood Experiences can affect lifelong health and opportunity; prevention and protective factors are important.
- Narrative identity / autobiographical memory research: people form identity by integrating life experiences into a coherent self-story; self-defining memories are especially important.

## 結論

このサービスが目指す「パーソナル」は、性格タイプや診断ではない。

その人がどんな体験をし、何を大事にし、誰と関わり、何に傷つき、何に救われ、どう変わってきたかを、時間軸と文脈で扱うこと。

その人のことをファーストにするなら、記憶体は情報を多く持つより、意味のある文脈を正しく扱う必要がある。
