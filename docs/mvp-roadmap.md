# MVP Roadmap

## MVPの目的

最初の目的は、すべてのデータを取り込むことではない。

**ユーザーが30秒〜数分で始められ、最初の記憶が残り、また使いたくなること。**

初回でZIPインポートを要求しない。

## MVPで検証する仮説

1. 人は「自分の記憶体」という概念に価値を感じるか
2. 相談AIではなく記憶体として受け入れられるか
3. シェア入力だけで自然に記憶が増えるか
4. ランダムTipや過去比較で再訪する理由が生まれるか
5. 長時間チャットなしで価値を出せるか
6. AIコストを抑えたまま体験価値を出せるか

## MVPで作るもの

### 1. オンボーディング

- 短い説明
- 初回診断
- ドットキャラ生成
- 初期プロフィール生成
- 最初の記憶登録

診断は長くしすぎない。

ただし、若者向けに「結果が良い」体験にする。

### 2. 最初の記憶登録

質問例:

- 最近考えていることは？
- 今大事にしていることは？
- 忘れたくない人や出来事は？
- 最近ハマっていることは？

登録後に、記憶体が以下のように反応する。

> 最初の記憶を覚えました。
> これは「価値観」と「今の関心」に入れておきます。

### 3. シェア入力

スマホの共有メニューから受け取れるようにする。

最初に対応する入力:

- テキスト
- URL
- ChatGPT / Claude から共有された本文
- メモの共有

処理:

1. 共有テキストを受け取る
2. 記憶候補を抽出
3. ユーザー確認
4. 保存

### 4. 記憶一覧

チャットではなく、記憶の引き出しUIにする。

初期カテゴリ:

- 最近の自分
- 人物
- 趣味
- 人生イベント
- 価値観
- 悩み
- 比較

### 5. Tip

ホーム画面に低コストで表示する。

- 去年の今日
- 最近増えている話題
- 忘れていた記憶
- 人物に関する記憶
- 価値観の変化

Tipは事前生成してキャッシュする。

### 6. 検索 / 質問

長時間チャットにはしない。

検索と短い回答を中心にする。

例:

- 妻ってどんな人？
- 最近の自分は何を考えている？
- 去年の俺ならどう思う？
- ゲーム開発について昔何を考えていた？

回数制限を入れる。

### 7. エクスポート

MVPでも最低限エクスポートを用意する。

- memories.json
- markdown summary

「囲い込まない」を最初から示す。

## MVPではやらないこと

- 無制限チャット
- 画像大量解析
- Googleフォト全量同期
- Gmail連携
- DM取り込み
- 常時監視
- 録音
- 画面解析
- 死者の人格再現
- 家族アカウント共有
- 複雑な権限管理

## 初回体験案

### 画面1

> AIが変わっても、あなたの人生の文脈は失われない。

### 画面2

> この子は相談AIではありません。
> あなたの記憶を整理し、必要な時に思い出させる存在です。

### 画面3

診断開始。

### 画面4

キャラクター誕生。

### 画面5

最初の記憶を登録。

### 画面6

ホーム。

- 今日のTip
- 最近の記憶
- 記憶を追加
- シェアで追加する方法

## ZIPインポートの位置づけ

初回には出さない。

設定画面や数日後の案内で出す。

表示文言:

> 過去のChatGPT履歴から、大事な記憶を探せます。
> これは上級者向けです。まずはシェア保存から始めても十分育ちます。

## MVPの技術方針

### Frontend

- スマホWebまたはPWA優先
- 後からネイティブアプリ化
- シェア拡張が重要なため、早い段階でiOS/Android対応を検討

### Backend

- API server
- DB
- vector search
- queue worker
- background job

### AI処理

- 低コストモデルで抽出
- Embedding作成
- 高性能LLMは最終文章生成だけ
- Tipはキャッシュ

## 成功指標

### 初回

- 診断完了率
- 最初の記憶登録率
- 初日離脱率

### 継続

- 7日後に記憶が2件以上あるか
- 30日後にシェア入力を使ったか
- Tip閲覧率
- 検索利用率

### コスト

- 1ユーザーあたり月間AIコスト
- 1記憶候補生成あたりコスト
- 1検索回答あたりコスト

## 最初の開発順

1. README / docs 整備
2. データモデル定義
3. 記憶登録API
4. 記憶一覧UI
5. 手動テキスト取り込み
6. 記憶候補抽出
7. ユーザー承認UI
8. Embedding検索
9. Tip生成
10. シェア入力
11. JSONエクスポート
12. ChatGPT ZIPインポート試作

## 判断

最初のMVPは、全連携を目指さない。

まず、ユーザーが「これ覚えて」を自然にできる状態を作る。

そこから、ChatGPT ZIP、Xアーカイブ、Googleフォト、GitHubへ広げる。
