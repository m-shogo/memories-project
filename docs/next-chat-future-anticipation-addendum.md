# Next Chat Future Anticipation Addendum

## Decision

一般的なおすすめ機能はMVP/P1で採用しない。

正式採用するのは、ユーザーが既に選んだ興味の続きを支える機能。

```txt
過去: 振り返り
現在: 棚と進行
未来: 続き・発売予定・行きたい場所
```

## Added Docs

- `docs/future-anticipation-and-following-spec.md`
- `docs/future-anticipation-ticket-backlog.md`

## P1 Scope

最初は漫画だけ。

```txt
漫画棚
→ この作品を追う
→ 続刊待ち
→ 次巻予定
→ 発売日カレンダー
→ 来月の楽しみ箱
→ 発売後に見たい/読了へ更新
```

## Notification Default

```txt
アプリ内のみ
```

Optional:

- 週1まとめ
- 重要作品だけ即時
- すべて通知しない

## Explicit No-Go

- generic recommendation feed
- personality-based recommendation
- sponsored recommendation
- all-title auto-follow
- default push notifications
- affiliate purchase links in MVP

## P2 Candidates

- anime next season
- podcast new episode
- movie streaming start
- creator follow
- explainable discovery
- game release / major update

## Product Principle

```txt
おすすめするのではなく、ユーザーが自分で選んだ棚の続きを支える。
```
