## Binding decisions

### Scenic hierarchy

```txt
Memory value
> practical shelf utility
> reflection
> scenery and attachment
> Town customization
```

Sceneryは重要だが、Memory-first hierarchyを逆転させない。

### Landscape

Prototypeには次を含める。

- wide sky
- sea / coast / beach
- narrow river or stream
- bridge
- Memory Tree
- open ground / negative space
- four time modes
- four seasons

### Camera

- single-screen fitを必須にしない
- finger dragによるbounded pan
- authored landmark anchors
- central-groveへのHome action
- free rotationなし
- avatar walkingなし
- gestureなしのDOM route equivalence

### Attachment

- 景色を好きになることを評価する
- 滞在時間最大化だけを成功指標にしない
- Townのための記憶水増しを誘導しない
- 川・海をgame economyへ接続しない
