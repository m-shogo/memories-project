# Third Party Data Policy

## 目的

このサービスはユーザー本人の記憶体だが、取り込まれるデータには他人の人生が必ず混ざる。

LINE、DM、メール、写真、家族会話、仕事ログ、SNS返信、AIチャット内の相談相手情報などは、ユーザーだけの情報ではない。

このポリシーは、第三者のプライバシーを守りながら、ユーザー本人の人生文脈を残すための境界線を定義する。

## 最上位原則

**他人の秘密を、ユーザーの記憶体の価値にしない。**

ユーザーの人生文脈として扱えるのは、他人そのものの評価や秘密ではなく、ユーザー本人から見た関係性・出来事・感情・影響である。

## 第三者データとは

以下を含む。

- LINE / DM / メール / Discord / Slackで相手が書いた文章
- 家族・恋人・友人・同僚の個人情報
- 他人の病気、悩み、恋愛、金銭、家庭事情
- 写真に写る他人の顔・位置・行動
- 子どもや未成年の情報
- 職場の顧客・同僚・取引先情報
- SNS返信や引用に含まれる他人の情報

## 扱ってよいもの

### ユーザー本人の関係性

例:

- 妻と旅行を大事にしていた
- 父の考え方に影響を受けていた
- 友人との会話が支えになっていた
- 家族との食事が安心につながっていた

### 共有された出来事

例:

- 卒業式後に友人と写真を撮った
- 家族で焼肉へ行った
- 旅行の計画を一緒にした

### ユーザー本人の感情

例:

- その会話で安心した
- その出来事が寂しかった
- その人との関係を大切に感じていた

## 扱わないもの

### 他人の秘密

- 相手の病気
- 相手の金銭問題
- 相手の恋愛事情
- 相手の家庭問題
- 相手の性的情報
- 相手のメンタル情報

原則:

- 原文保存しない
- LLMへ送らない
- Tipに出さない
- 家族共有しない

### 他人の診断・評価

禁止:

- 妻はこういう性格です
- 父は毒親です
- 友人は依存的です
- 同僚は能力が低いです

許容:

- あなたの記録では、奥様との間に旅行や結婚式準備の記憶が多くあります
- 父親に関する記録では、仕事観への影響がいくつか見られます
- その友人との会話は、当時の支えになっていたようです

### 他人の行動監視

禁止:

- 元恋人がどこに行っていたか探す
- パートナーの浮気を推測する
- 家族の嘘を探す
- 同僚の弱点を分析する

## Source別方針

### LINE / DM

高感度デフォルト。

- 原文保存: 非推奨
- LLM送信: マスク済み要約のみ
- Tip: 原則禁止
- 共有: 禁止デフォルト
- 検索: 要約中心

保存してよい例:

- 妻と結婚式の準備をしていた
- 友人と卒業式後に焼肉へ行った

保存しない例:

- 相手の秘密
- 相手の病気
- 相手の住所や電話番号
- 相手を責める材料

### Gmail

超高感度。

MVPでは原則後回し。

扱うなら、航空券・ホテル予約などの人生イベント要約のみ。

### Slack / Work chat

会社データとして扱う。

- 会社情報は保存しない
- 同僚分析しない
- 顧客情報を保存しない
- ユーザー本人の仕事観や転機のみ扱う

### Photos

写真に写る他人は第三者情報。

- 顔認識しない
- 子ども写真は特に高感度
- 場所情報は丸める
- 写真本体よりイベント要約を優先

### X / Public SNS

公開情報でも、相手の返信や引用は慎重に扱う。

- 公開投稿は比較的扱いやすい
- 他人への攻撃や炎上は原文拡散しない
- 他人の個人情報を再掲しない

## UI警告

LINEやDMなどをインポートする前に表示する。

> このデータには、あなた以外の人の会話や個人情報が含まれる可能性があります。このサービスは相手の性格診断や監視には使いません。原文保存ではなく、あなたとの関係性や出来事の要約を優先します。

## Policy Matrix

| Data | Save | Raw | LLM | Tip | Share |
|---|---|---|---|---|---|
| 自分だけのメモ | yes | optional | yes | yes | owner/default |
| LINE日常 | summary | hidden | masked | no | no |
| 相手の秘密 | exclude | no | no | no | no |
| 家族イベント | approve | hidden | minimized | opt-in | limited |
| 子ども情報 | approve | no/default | minimized | no | no/default |
| 会社情報 | exclude | no | no | no | no |
| 公開SNS投稿 | approve/auto | yes | yes | maybe | owner |

## 実装要件

- `thirdPartyRisk` scoreを必ず持つ
- `speaker` を可能な限り識別する
- 自分の発言と相手の発言を分ける
- 原文引用は本人発言を優先する
- 相手発言の引用は原則避ける
- 人物カードは「ユーザーから見た関係性」に限定する
- blame / surveillance intent を検出する
- third-party private data は export/share から除外する

## 禁止パターン

- パートナー診断
- 元恋人監視
- 家族を責める証拠探し
- 同僚分析
- 子どもの性格固定
- 相手の秘密の記憶化
- 第三者情報の家族共有混入

## 結論

このサービスは、ユーザー本人の人生文脈を守る。

ただし、その人生には他人が登場する。

だからこそ、他人をデータ化するのではなく、ユーザー本人がその関係をどう経験したかだけを慎重に扱う。
