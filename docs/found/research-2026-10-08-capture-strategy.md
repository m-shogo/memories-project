# Found capture strategy research — 2026-10-08

## New evidence

Apple Share Extensions can receive text and attachments such as links, images, and videos from the host app. This makes explicit sharing a strong cross-source baseline.

Native saved-item sync is fragmented. YouTube's official API rejects listing Watch Later items with playlistOperationUnsupported. X has bookmark endpoints, but API access and pricing can change. Native-save sync should therefore be an optional adapter, not the core product dependency.

Pocket shut down on July 8, 2025 after Mozilla said saving and consumption habits had evolved. Omnivore also shut down after acquisition. Generic read-later storage alone is not a sufficient product thesis; portability and durable custody matter.

Current willingness-to-pay signals exist for automatic organization. Recall lists automatic smart tags and knowledge-graph features in a $10/month annual-billing plan and says it serves 700,000+ learners. mymind lists intelligent bookmarks and automatic Smart Spaces at $7.99/month.

## Recommended capture ladder

1. Explicit Share Extension / sharesheet.
2. Paste and bulk import.
3. Browser extension for desktop convenience.
4. Official API sync only where stable and economical.
5. User-controlled import/export.

Do not promise universal automatic sync from every platform's private Saved/Favorites collection.

## Product change

Found should not initially ask users to replace every native Save button. Make Share → Found fast, preserve the original source, classify automatically, and add source adapters over time.

Data export should be first-class because shutdown history in this category creates a trust problem.

## Next experiment

The biggest activation risk is habit substitution: will people choose Share → Found often enough instead of each app's native Save/Favorite action?

Test that before investing heavily in source-specific sync adapters.
