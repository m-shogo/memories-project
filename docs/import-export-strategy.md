# Import / Export Strategy

## 方針

このサービスの強みは、あらゆる場所に散らばった人生の断片を受け取れること。

ただし、最初から全サービスを自動同期する必要はない。

大事なのは、入力元ごとに個別実装を増やすことではなく、共通のインポートパイプラインを作ること。

## 入力の優先順位

### Phase 1: シェア入力

最優先。

スマホで以下の導線を作る。

1. ChatGPT / Claude / Safari / X / YouTube / メモなどで共有
2. 記憶体アプリを選択
3. アプリが内容を受け取る
4. AIが記憶候補を抽出
5. ユーザーが承認
6. 保存

ユーザーに ZIP やファイル操作を要求しない。

最初に使ってもらうには、この導線が一番重要。

### Phase 2: テキスト貼り付け

シェアが使えない場合の代替。

- ChatGPTの週まとめ
- Claudeの会話まとめ
- 日記
- メモ
- 自分で書いた振り返り

を貼るだけで記憶候補を作る。

### Phase 3: ChatGPT エクスポート ZIP

ヘビーユーザー向け。

初回導線にはしない。

設定画面やオンボーディング後の「過去の記憶を一括インポート」に置く。

理由:

- ZIPという概念が一般ユーザーには難しい
- スマホだけだとファイル操作で離脱しやすい
- エクスポート待ちがある
- ダウンロードリンク期限がある
- いきなり全履歴解析するとコストが読みにくい

処理方針:

1. ZIPを受け取る
2. conversations.json などの会話データを検出
3. まずメタデータだけ解析する
4. 会話タイトル、日時、量、キーワードを抽出
5. 人生記憶っぽい会話を候補化
6. 優先度の高い会話だけ深掘り
7. ユーザー承認後に保存

最初から全チャット全文をEmbeddingしない。

### Phase 4: X / Twitter アーカイブ

Xは公式にアカウントデータアーカイブを取得できるため、相性が良い。

取り込める可能性があるもの:

- 投稿
- 返信
- DM
- いいね
- フォロー情報

使い道:

- 昔の自分の価値観分析
- 興味の変化
- 仕事・趣味・投資などの発言推移
- 2018年の自分ならどう思うか

注意:

- すべて保存しない
- 炎上・黒歴史・個人情報を扱うため、プライバシー設定を強くする
- DMは初期対象から外してもよい

### Phase 5: Googleフォト

画像本体を大量保存しない。

保存するのは、写真の意味と参照情報。

- 撮影日時
- 場所
- アルバム名
- タグ
- 簡易要約
- Googleフォト上の参照ID

MVPでは画像本体を保存しない。

「この画像も残す」とユーザーが明示した場合だけ保存を検討する。

画像解析はコストが重いため、無料では限定する。

### Phase 6: GitHub

エンジニア向けには非常に相性が良い。

- コミット
- PR
- Issue
- Release
- README

から、人生の仕事・開発・学習の文脈を作れる。

例:

- いつゲーム開発を始めたか
- 何に詰まっていたか
- どの時期に何を作っていたか
- 技術スタックの変化

### Phase 7: Notion / Google Drive / Calendar / Gmail

優先度は後ろ。

ただし、人生アーカイブとしては強い。

- Notion: 日記、メモ、企画
- Google Drive: PDF、文書、エクスポートデータ
- Calendar: 旅行、予定、人生イベント
- Gmail: 航空券、ホテル、予約、イベント通知

Gmailは権限が重く怖く見えやすいため、初期MVPでは避けてもよい。

## 共通インポートパイプライン

入力元が何であっても、最終的には以下へ正規化する。

```ts
SourceInput
  -> RawRecord
  -> MemoryCandidate
  -> ApprovedMemory
  -> Embedding / Index
```

### SourceInput

外部から受け取った生データ。

- shared text
- shared url
- uploaded file
- export zip
- api response
- image metadata

### RawRecord

読み取り可能な単位に分解したもの。

- 1会話
- 1投稿
- 1写真
- 1コミット
- 1予定
- 1文書

### MemoryCandidate

AIが抽出した記憶候補。

まだ確定保存しない。

### ApprovedMemory

ユーザー承認済み、または低リスク自動保存済みの記憶。

## エクスポート方針

このサービスは囲い込まない。

いつでもユーザーが自分の記憶を持ち出せるようにする。

### Export v1

- memories.json
- people.json
- events.json
- topics.json
- values.json
- source_refs.json
- markdown summary

### Export v2

- family graph
- timeline
- embeddings metadata
- migration guide for other AI tools

## 重要な思想

このサービスは、元データを全部抱え込む必要はない。

写真はGoogleフォトにあってよい。

会話はChatGPTにあってよい。

コードはGitHubにあってよい。

このサービスは、**どこに何があり、それが人生の中でどういう意味を持つか**を覚える。

つまり、人生の保管庫ではなく、人生の索引である。
